# 第三方素材与署名

`lib/ui/sprites/` 中的 `idle.png`、`think.png`、`working.png`、`wait.png`、`celebrate.png`、`error.png`、`eat.png`、`joy.png`、`drag.png` 直接来自 [vlln/whale-girl](https://github.com/vlln/whale-girl)，未作图像修改。

- 来源版本：[`9c32d7a39a45148076f8ad2fdaad2dc2420eedb3`](https://github.com/vlln/whale-girl/tree/9c32d7a39a45148076f8ad2fdaad2dc2420eedb3/lib/assets/characters/whale-girl)
- 上游素材清单：[manifest.json](https://github.com/vlln/whale-girl/blob/9c32d7a39a45148076f8ad2fdaad2dc2420eedb3/lib/assets/manifest.json)
- 仓库许可：[MIT](https://github.com/vlln/whale-girl/blob/9c32d7a39a45148076f8ad2fdaad2dc2420eedb3/LICENSE)，完整原文同时保存在 `lib/ui/sprites/LICENSE`。
- 角色原设计署名：**ZipZipPipe**（[Bilibili](https://space.bilibili.com/4168597)）。上游 README 说明这些动画素材根据其「鲸鱼娘」表情包角色设计生成；本项目沿用该署名，不将角色设计宣称为原创。

本说明记录上游公开的仓库许可与角色署名；上游未在这些文件中另附角色原作的独立授权声明。
